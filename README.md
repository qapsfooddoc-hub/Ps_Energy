# ระบบเว็บแอปพลิเคชันแดชบอร์ดและลงบันทึกข้อมูลค่าใช้จ่ายด้านพลังงาน 2568 (Energy Usage Dashboard & Data Logging)

เว็บแอปพลิเคชันระบบบริหารจัดการและสรุปค่าใช้จ่ายด้านพลังงาน (น้ำ, ไฟฟ้า, น้ำมันเชื้อเพลิง, แก๊ส LPG) ที่ถอดแบบมาจากไฟล์ Excel **สรุปค่าใช้จ่ายด้านพลังงาน 2568** พร้อมฟอนต์ **Niramit** ดีไซน์สไตล์ Modern Dark Glassmorphic สวยงามและรองรับการใช้งานบนมือถือ (Responsive)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **📊 แดชบอร์ดภาพรวม (Interactive Dashboard)**
   - แสดงตัวเลขสรุปสะสมปี 2568: ค่าใช้จ่ายรวม (191.57M ฿), ยอดผลิตรวม (455,271 ตัว), ค่าใช้จ่ายเฉลี่ย (423.37 ฿/ตัว)
   - กราฟแท่งซ้อน (Stacked Bar Chart) แสดงค่าใช้จ่ายแยกตามประเภทพลังงานรายเดือน
   - กราฟโดนัทแสดงสัดส่วนค่าใช้จ่าย (%)
   - กราฟเส้นแสดงแนวโน้มค่าใช้จ่ายต่อยอดการผลิต (บาท/ตัว)
   - กราฟแท่งแสดงค่าไฟฟ้าแยกตามสถานที่/มิเตอร์ย่อย

2. **📝 ฟอร์มลงบันทึกข้อมูลรายเดือน (Monthly Data Logging)**
   - เลือกลงข้อมูลรายเดือน (มกราคม - ธันวาคม)
   - ป้อนยอดการผลิตประจำเดือน (จำนวนสุกร/ตัว)
   - ป้อนปริมาณการใช้และจำนวนเงิน (บาท) ของน้ำ, ไฟฟ้า, น้ำมัน, แก๊ส LPG
   - คำนวณอัตราส่วน `ปริมาณการใช้/ยอดผลิต`, `ค่าใช้จ่าย/ยอดผลิต` และ `รวมจำนวนเงิน` ให้อัตโนมัติทันทีที่พิมพ์
   - บันทึกหมายเหตุประจำเดือน

3. **🏢 จัดการ & บันทึกมิเตอร์บิลย่อย (Sub-Bill Meters)**
   - บันทึกรายละเอียดมิเตอร์ย่อยค่าน้ำ 7 รายการ (เช่น บ้านกู๋พจน์, ออฟฟิศคลัง 3, คลัง 3/4, โรงฆ่าเก่า, เฟส 3,4, เฟส 5,6, โรงกุนเชียง)
   - บันทึกรายละเอียดมิเตอร์ย่อยค่าไฟฟ้า 7 รายการ (เช่น หน้าร้านเก่า, คลังสินค้า 1, บ้านกู๋พจน์, ออฟฟิศคลัง 3, คลังสินค้า 4, เฟส 5-6, P&P)
   - ปุ่มกดคำนวณรวบยอดบิลย่อยส่งไปยังตารางสรุปประจำเดือนและแดชบอร์ดให้อัตโนมัติ

4. **📄 ตารางสรุปรูปแบบ Excel (Spreadsheet Replica View)**
   - ถอดแบบมาจากตารางสเปรดชีต Excel ประจำเดือน พร้อมช่องลงชื่อผู้จัดทำ (QA) / ผู้ตรวจสอบ (EMR)

5. **📑 ส่งออกและบันทึกข้อมูล (Export & Storage)**
   - บันทึกข้อมูลลงใน LocalStorage ของเบราว์เซอร์ให้อัตโนมัติ
   - ส่งออกข้อมูลเป็นไฟล์ Excel (`.xlsx`) สมบูรณ์พร้อมชีทรายเดือนและชีทสรุป
   - รองรับการสั่งพิมพ์ / บันทึก PDF (Print View)
   - ปุ่มรีเซ็ตข้อมูลกลับเป็นค่าเริ่มต้นปี 2568 จากไฟล์ Excel เดิมได้ตลอดเวลา

## 🎨 การออกแบบ (Design System)
- **Font**: Google Fonts **Niramit** (300, 400, 500, 600, 700)
- **Theme**: Sleek Dark Glassmorphism พร้อมสวิตช์ Dark/Light Mode
- **Responsive**: รองรับการแสดงผลทุกขนาดหน้าจอ (Desktop, Tablet, Mobile)
